Zephyr 对 ARC 处理器的支持状态
##############################

概述
****

本页介绍 Zephyr 对 ARC 处理器的当前支持状态以及部分未来计划。请注意

 * 这些计划没有确切的截止日期
 * 软件功能需要相应的硬件，并且硬件必须正确配置
 * 并非所有功能都能同时启用

备注
****

.. [#f1] 在 SMP 系统上，CCM 的使用受到限制
.. [#f2] 由于硬件限制，具有安全功能（SecureShield）的系统除外
.. [#f3] 我们仅支持保存和恢复任务上下文中的 ACCL/ACCH 寄存器。其余 DSP/AGU 寄存器的保存和恢复尚未实现，但内核本身不使用这些寄存器。因此，每个核心上可以有一个任务安全地使用 DSP/AGU。
.. [#f4] QEMU 并不支持 ARC 处理器的所有硬件功能。有关详细信息，请查阅 ARC QEMU 文档
.. [#f5] 仅单核目标支持单线程内核
.. [#f6] 目前仅支持 ARC VPX 标量移植。本移植不包含对 VPX 向量流水线、VCCM 和 STU 的支持，这些功能需要额外开发和/或集成其他运行时。

VPX 向量寄存器
--------------
Zephyr 支持一种受限的 VPX 向量寄存器共享方式，称为协作式共享。使用这些寄存器的线程必须在相关代码段的开始和结束处分别调用 :c:func:`arc_vpx_lock` 和 :c:func:`arc_vpx_unlock` ，以控制对该资源的访问。

.. note::
    如果系统具有多个 CPU，应用开发者必须在线程尝试获取协作锁之前将其绑定到单个 CPU，并确保在线程等待或持有该协作锁期间不修改其 CPU 亲和性。

配置选项
========

启用配置选项 :kconfig:option:`CONFIG_ARC_VPX_COOPERATIVE_SHARING` 时，将选用 VPX 向量寄存器的协作式共享。
