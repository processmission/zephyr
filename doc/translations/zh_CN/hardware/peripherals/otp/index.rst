.. _otp:

一次性可编程（OTP）存储器设备
#############################

概述
****

OTP 存储器设备用于管理预期永久保存数据的存储器。这类存储器通常在制造过程中完成配置，但某些用例需要在生命周期的后续阶段对 OTP 存储器进行编程（例如单调计数器、密码密钥等）。
