USB 厂商和产品标识符
********************

Zephyr 项目的 USB 厂商 ID（Vendor ID，VID）为 ``0x2FE3``。当厂商将 Zephyr USB 设备支持集成到自己的产品中时，不得使用 Zephyr USB 厂商 ID。

每个 USB :zephyr:code-sample-category:`示例<usb>` 都有自己唯一的产品 ID（Product ID，PID）。USB 维护者（如果已指定）或 Zephyr 技术指导委员会（Technical Steering Committee，TSC）可以根据有充分理由并有文档记录的请求分配其他 USB 产品 ID。

目前使用的产品 ID 如下：
