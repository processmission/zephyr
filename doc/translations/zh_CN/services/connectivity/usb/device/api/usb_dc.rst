USB 设备控制器驱动 API（已弃用）
################################

USB 设备控制器驱动 API 在 :zephyr_file:`include/zephyr/drivers/usb/usb_dc.h` 中描述，有时也称为 ``usb_dc`` API。

该 API 在设计上有一些限制，它不遵循 :ref:`device_model_api`，并且正被 :ref:`udc_api` 取代。
