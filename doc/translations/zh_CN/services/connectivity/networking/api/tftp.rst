TFTP
####

Zephyr 提供了一个简单的 TFTP 客户端库，可通过 :kconfig:option:`CONFIG_TFTP_LIB` Kconfig 选项启用。

该库的用法详见 :zephyr:code-sample:`TFTP 客户端示例应用 <tftp-client>`。
