链路层发现协议
##############

.. contents::
    :local:

概述
****

链路层发现协议（LLDP，Link Layer Discovery Protocol）是一种与厂商无关的链路层协议，网络设备用它来通告自己在有线以太网中的身份、能力和邻居信息。

更多信息请参见 `LLDP Wikipedia article <https://en.wikipedia.org/wiki/Link_Layer_Discovery_Protocol>`_。
