蓝牙 Mesh 配置文件
##################

蓝牙 Mesh 配置文件为低功耗蓝牙（Bluetooth Low Energy）增加了安全的无线多跳通信。本模块实现了 `Bluetooth Mesh Protocol Specification v1.1.1 <https://www.bluetooth.com/specifications/specs/mesh-protocol-1-1-1/>`_ 规范。

关于蓝牙 Mesh 的更多信息，请访问 `蓝牙 SIG 网站 <https://www.bluetooth.com/bluetooth-resources/?tags=mesh>`_ 了解。
