沟通与协作
##########

`Zephyr Discord 服务器 <https://chat.zephyrproject.org>`_ 是 Zephyr 开发者、贡献者和用户使用的主要聊天平台。

`Zephyr 项目邮件列表 <https://lists.zephyrproject.org/g/main/subgroups>`_ 是项目成员、贡献者和社区使用的辅助沟通工具。针对特定主题设有专门的邮件列表，其中多个列表公开且开放加入。当 Discord 无法使用或不适合讨论相关话题时，始终可以使用邮件列表进行沟通。

一般而言，缺陷及其他问题应通过 `GitHub Issues <https://github.com/zephyrproject-rtos/zephyr/issues>`_ 报告，而不应群发到邮件列表。代码审查也遵循同样的原则。
