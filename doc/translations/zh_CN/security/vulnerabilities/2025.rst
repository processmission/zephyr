CVE-2025
########

:cve:`2025-1673`
----------------

在 dns_validate_msg 中调用 crc16_ansi 和 strlen 时发生越界读取

恶意或格式错误的 DNS 数据包如果没有有效载荷，可能引发越界读取，从而导致崩溃（拒绝服务）或计算错误。

- `Zephyr 项目缺陷跟踪系统 GHSA-jjhx-rrh4-j8mx <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-jjhx-rrh4-j8mx>`_

此问题已在 main 中针对 v4.1.0 修复。

- `main 的修复 PR 82072 <https://github.com/zephyrproject-rtos/zephyr/pull/82072>`_

- `4.0 的修复 PR 82289 <https://github.com/zephyrproject-rtos/zephyr/pull/82289>`_

- `3.7 的修复 PR 82288 <https://github.com/zephyrproject-rtos/zephyr/pull/82288>`_

:cve:`2025-1675`
----------------

dns_copy_qname 中的越界读取

- `Zephyr 项目缺陷跟踪系统 GHSA-2m84-5hfw-m8v4 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-2m84-5hfw-m8v4>`_

- `main 的修复 PR 82072 <https://github.com/zephyrproject-rtos/zephyr/pull/82072>`_

- `4.0 的修复 PR 82289 <https://github.com/zephyrproject-rtos/zephyr/pull/82289>`_

- `3.7 的修复 PR 82288 <https://github.com/zephyrproject-rtos/zephyr/pull/82288>`_

:cve:`2025-7403`
----------------

Bluetooth：bt_conn_tx_processor 的不安全处理

bt_conn_tx_processor 中的不安全处理会导致 use-after-free，进而造成 write-before-zero。写入的 4 个字节由攻击者控制，可实现精确的内存破坏。

- `Zephyr 项目缺陷跟踪系统 GHSA-9r46-cqqw-6j2j <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-9r46-cqqw-6j2j>`_

此问题已在 main 中针对 v4.2.0 修复。

- `main 的修复 PR 90975 <https://github.com/zephyrproject-rtos/zephyr/pull/90975>`_

:cve:`2025-10456`
-----------------

Bluetooth：半任意地使 BLE 目标设备发送断开连接请求的能力

在 Bluetooth Low Energy（BLE）固定通道（如 SMP 或 ATT）的处理中发现了一个漏洞。具体而言，攻击者可利用一个缺陷，使 BLE 目标设备（即受攻击的设备）尝试断开固定通道，而 Bluetooth 规范不允许这样做。这会导致未定义行为，包括可能的断言失败、崩溃或内存损坏。

- `Zephyr 项目缺陷跟踪系统 GHSA-hcc8-3qr7-c9m8 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-hcc8-3qr7-c9m8>`_

此问题已在 main 中针对 v4.2.0 修复。

- `main 的修复 PR 93576 <https://github.com/zephyrproject-rtos/zephyr/pull/93576>`_

- `3.7 的修复 PR 100474 <https://github.com/zephyrproject-rtos/zephyr/pull/100474>`_

Bluetooth：Mesh：gen_prov_start 中的越界写入

pb_adv.c 中的 gen_prov_start 函数存在潜在的越界写入（OOB Write）漏洞。接收数据的完整长度未经任何数据大小校验便被复制到 link.rx.buf 接收缓冲区中。

- `Zephyr 项目缺陷跟踪系统 GHSA-8wvr-688x-68vr <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-8wvr-688x-68vr>`_

:cve:`2025-12890`
-----------------

Bluetooth：peripheral：对畸形连接请求的处理不当

对 interval 设置为 1（本应不合法）且 chM 为 0x7CFFFFFFFF 的畸形 Connection Request 处理不当会触发崩溃。此后该 peripheral 设备将无法再被连接。

- `Zephyr 项目缺陷跟踪系统 GHSA-8hrf-pfww-83v9 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-8hrf-pfww-83v9>`_

此问题已在 main 中针对 v4.2.0 修复。

- `main 的修复 PR 89955 <https://github.com/zephyrproject-rtos/zephyr/pull/89955>`_

:cve:`2025-12899`
-----------------

net：icmp：越界内存读取

Zephyr 网络协议栈中的缺陷会使包含 ICMP 类型 128 的 IPv4 数据包被误判为 ICMPv6 Echo Request。这会导致越界内存读取，并在网络子系统中构成潜在的信息泄露漏洞。


- `Zephyr 项目缺陷跟踪系统 GHSA-c2vg-hj83-c2vg <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-c2vg-hj83-c2vg>`_

此问题已在 main 中针对 v4.3.0 修复。

- `main 的修复 PR 98780 <https://github.com/zephyrproject-rtos/zephyr/pull/98780>`_

- `4.2 的修复 PR 98983 <https://github.com/zephyrproject-rtos/zephyr/pull/98983>`_

- `4.1 的修复 PR 98984 <https://github.com/zephyrproject-rtos/zephyr/pull/98984>`_

- `3.7 的修复 PR 98985 <https://github.com/zephyrproject-rtos/zephyr/pull/98985>`_
