:cve:`2021-3436`
----------------

Bluetooth：当已知绑定的身份地址时，在密钥分发阶段可能覆盖现有绑定

在分发身份地址信息期间，我们不会检查是否已存在具有相同身份地址的绑定。这意味着 RAM 中将创建重复条目，而最新条目会覆盖持久化存储中的现有条目。

此问题已在 main 中修复，将包含于 v2.6.0。

- `Zephyr 项目缺陷跟踪系统 GHSA-j76f-35mc-4h63 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-j76f-35mc-4h63>`_

- `main 的修复 PR 33266 <https://github.com/zephyrproject-rtos/zephyr/pull/33266>`_

- `2.5 的修复 PR 33432 <https://github.com/zephyrproject-rtos/zephyr/pull/33432>`_

- `2.4 的修复 PR 33433 <https://github.com/zephyrproject-rtos/zephyr/pull/33433>`_

- `1.14.2 的修复 PR 33718 <https://github.com/zephyrproject-rtos/zephyr/pull/33718>`_

:cve:`2021-3510`
----------------

Zephyr JSON 解码器错误解码数组的数组

使用 JSON_OBJ_DESCR_ARRAY_ARRAY 时，子数组的令牌类型为 JSON_TOK_LIST_START，但随后被赋给联合体的 object 部分。arr_parse 随后取得数组对象的偏移量（该对象与列表无关），将其视为相对于父对象的偏移量，并把子数组的长度存储在其中。

此问题已在 main 中修复，将包含于 v2.7.0。

- `Zephyr 项目缺陷跟踪系统 GHSA-289f-7mw3-2qf4 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-289f-7mw3-2qf4>`_

- `main 的修复 PR 36340 <https://github.com/zephyrproject-rtos/zephyr/pull/36340>`_

- `2.6 的修复 PR 37816 <https://github.com/zephyrproject-rtos/zephyr/pull/37816>`_

:cve:`2021-3581`
----------------

HCI 数据未正确校验导致 Bluetooth 协议栈内存溢出

在通过 HCI 命令设置 SCAN_RSP 的过程中，Zephyr Bluetooth 协议栈未有效检查传入 HCI 数据的长度。这会导致内存溢出，随后内存中的数据被覆盖，甚至可能造成任意代码执行。

此问题已在 main 中修复，将包含于 v2.6.0。

- `Zephyr 项目缺陷跟踪系统 GHSA-8q65-5gqf-fmw5 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-8q65-5gqf-fmw5>`_

- `main 的修复 PR 35935 <https://github.com/zephyrproject-rtos/zephyr/pull/35935>`_

- `2.5 的修复 PR 35984 <https://github.com/zephyrproject-rtos/zephyr/pull/35984>`_

- `2.4 的修复 PR 35985 <https://github.com/zephyrproject-rtos/zephyr/pull/35985>`_
