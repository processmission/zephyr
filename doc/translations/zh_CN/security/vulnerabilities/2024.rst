:cve:`2024-1638`
----------------

- `Zephyr 项目缺陷跟踪系统 GHSA-p6f3-f63q-5mc2 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-p6f3-f63q-5mc2>`_

- `main 的修复 PR 69170 <https://github.com/zephyrproject-rtos/zephyr/pull/69170>`_

:cve:`2024-3077`
----------------

Bluetooth：gatt_find_info_rsp 中的整数下溢。恶意 Bluetooth LE 设备可通过发送格式错误的 gatt 数据包使受害的 Bluetooth LE 设备崩溃。

- `Zephyr 项目缺陷跟踪系统 GHSA-gmfv-4vfh-2mh8 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-gmfv-4vfh-2mh8>`_

- `main 的修复 PR 69396 <https://github.com/zephyrproject-rtos/zephyr/pull/69396>`_

Bluetooth：空指针解引用导致的 DoS。

-----------------

- `main 的修复 PR 80396 <https://github.com/zephyrproject-rtos/zephyr/pull/80396>`_

:cve:`2024-11263`
-----------------

arch：riscv：userspace：CONFIG_RISCV_GP=y 时存在潜在安全风险

恶意线程可能破坏 gp 寄存器，最好的情况是导致整个系统出现硬故障，最坏的情况则可能诱使系统访问另一组随机的全局符号。

- `Zephyr 项目缺陷跟踪系统 GHSA-jjf3-7x72-pqm9 <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-jjf3-7x72-pqm9>`_

此问题已在 main 中针对 v4.0.0 修复。

- `main 的修复 PR 81155 <https://github.com/zephyrproject-rtos/zephyr/pull/81155>`_

- `3.7 的修复 PR 81370 <https://github.com/zephyrproject-rtos/zephyr/pull/81370>`_
