安全标准与 Zephyr
#################

过去，各组织独立管理网络安全，自行定义评估和响应规程。如今，政府正通过新的强制性规定和安全标准越来越多地监管这一领域。这些标准为联网产品定义了具体的准则和合规要求。

本节评估这些安全标准对 Zephyr 项目本身以及下游产品开发者的影响。目标是向开发者提供所需信息，以便使用 Zephyr 构建可认证、合规的产品。
